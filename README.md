# Item Catalog Full Stack
A full-stack web application developed as part of the ** Udacity Full Stack Web Developer Nanodegree.**

This project represents my work from 2019 and combines a Python/Flask web application with database management, user authentication, and Linux server deployment.

## About the Project
The application is a perfume catalog that allows users to browse different categories and manage their own items.

### Authenticated users can:

- Add items
- Edit their own items
- Delete their own items
- Browse items by category
- Sign in using Google authentication

## Deployment
The application was deployed as part of the Udacity Linux Server Configuration project.

The deployment included:

- Linux server configuration
- SSH security
- UFW firewall configuration
- Apache web server
- PostgreSQL database
- Python WSGI configuration
Virtual environment
- Google OAuth configuration
Detailed deployment documentation will be included in the deployment directory.

## Background
This project was completed as part of my learning journey toward becoming a Full Stack Web Developer.
